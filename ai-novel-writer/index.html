An open-source AI novel writing app, from story planning to revision.

Pagekin, formerly AI Novel Writer, is a free, open-source desktop app for fiction writers. Plan a story, draft a chapter, select review notes and compare revisions before accepting them. Configure your own cloud service or local Ollama model. Cloud usage can cost extra.

  • Windows / macOS
  • Cloud & local models
  • GPL-3.0 Open Source
  • Autonomous outlines & blueprints

PRODUCT POSITION

先整理设定，再写一章，由作者决定怎样修改。

书童把人物、世界观、章节蓝图与正文放在同一项目中。先检查当前章节要发生什么，再让模型生成草稿。审稿建议可以选择，修改结果可以逐段比较。

既可直连 DeepSeek、OpenAI、Gemini 等商用云端模型，也可接入本地 Ollama 开源模型。系统围绕当前章节蓝图、相关角色资料、世界观设定与历史摘要组织上下文，配合自动化审稿报告与修稿闭环，帮助作者发现设定和人物前后不一致的问题。

模型提供草稿和建议，作者决定故事方向以及采用哪些内容。

PRODUCT POSITION

Plan the story, draft a chapter, then choose what to change.

Pagekin keeps character notes, worldbuilding, chapter blueprints and prose in one project. Check the chapter plan, generate a draft, then choose review suggestions and compare revisions.

Compatible with both cloud models (DeepSeek, OpenAI, Gemini) and local offline LLMs (Ollama). The active blueprint and relevant story material provide context for generation. Review notes help the author decide what to revise.

AI provides generative power while the author steers vision and decisions. Outlines, blueprints, and review findings help the author check story continuity.

TRACEABLE FLOW

从故事前提，一直走到下一章的上下文。

  1. 建立创作前提保存作品方向、关键矛盾和作者已经确认的原稿。
  2. 组织角色与世界观把人物、关系、规则和知识资料放回项目内部。
  3. 拆成大纲与章节蓝图让每一章有明确目标，而不是仅依赖一段临时提示词。
  4. 生成或导入章节草稿围绕当前章节资料调用本地或云端模型。
  5. 审稿、修稿、人工确认审稿意见可编辑和取舍，修订稿由作者决定是否合并。
  6. 形成定稿并继续定稿进入后续章节的连续性上下文。

TRACEABLE FLOW

From premise to the context that carries the next chapter.

  1. Define the premiseKeep direction, conflict, and approved manuscript material together.
  2. Build characters and world factsStore relationships, rules, and source material inside the project.
  3. Create outline and chapter blueprintsGive every chapter a deliberate target beyond a temporary prompt.
  4. Generate or import a draftCall a local or cloud model with chapter-specific context.
  5. Review, revise, approveEdit and select review notes before accepting a revision.
  6. Finalize and continueApproved copy becomes continuity context for future chapters.

CURRENT BOUNDARIES

它帮助你管理创作，但不会替代作者的判断。

  • 不承诺任意第三方 API 只换 URL 和 Key 就能接入。
  • 不替代作者的创意、事实核查、版权判断与最终审校。
  • 不提供在线发布、阅读社区或云端模型账号。

CURRENT BOUNDARIES

It manages the process; it does not replace the author.

  • Not every third-party API works by changing only a URL and key.
  • Creative decisions, fact checking, copyright judgment, and final review remain with the author.
  • It does not provide publishing, a reader community, or hosted model accounts.
  • The separately published DeepSeek Harness developer preview is frozen and does not replace the desktop app. See its own README for limitations.

FREQUENTLY ASKED QUESTIONS

常见问题与核心特性答疑

书童 Pagekin 与普通的 AI 聊天写作有什么不同？

书童 Pagekin 把人物、世界观、章节蓝图、草稿和修订保存在同一个写作项目中。作者可以生成一章草稿，选择审稿建议，再逐段比较并决定采用哪些修改。模型仍可能产生矛盾，最终内容由作者确认。

它只能接入本地模型吗？支持哪些云端与本地大模型？

你可以配置 DeepSeek、OpenAI 等兼容接口、Google Gemini 原生接口，或本地 Ollama。软件不附带模型和额度；云端模型费用由服务商另收。使用云端模型时，相关提示词与上下文会发送给该服务商。

它支持直接导入已经写好的前文进行续写吗？

可以导入自己的稿件继续创作，也可以选中一段正文续写、扩写或改写。生成结果需要作者检查；导入说明和支持格式以当前版本 README 为准。

FREQUENTLY ASKED QUESTIONS

Frequently Asked Questions

How is Pagekin different from writing with a standard AI chat? What is its core focus?

Pagekin stores characters, worldbuilding, chapter plans, drafts and revisions in one project. Generate a chapter, choose review notes and compare changes before accepting them. Models can still produce inconsistencies, so the author reviews the result.

Is it limited to local models? Which cloud and local models are supported?

Configure an OpenAI-compatible service, native Google Gemini, or local Ollama. No model or quota is bundled. Cloud providers can charge for usage and receive the prompts and context you send.

Can I import existing manuscripts to continue writing?

Yes. Import your manuscript to continue working, or select a passage to continue, expand or rewrite it. Check the current README for supported formats and review all generated text.
