PRODUCT POSITION

它提供的是创作编排层，不是又一个生成按钮。

AI Novel Writer 不内置模型额度，也不是在线小说平台。它负责保存项目状态、组织提示词和上下文、管理章节蓝图与草稿版本，并把生成、审稿和修稿串起来。

长篇创作时，系统围绕当前章节蓝图、相关角色、世界观、历史摘要和可选参考文风组织上下文。作者仍然决定故事写什么、哪些修改被接受、何时形成定稿。

v0.8.6 加固了作者原稿导入、可靠续写、明确模型路由与人工审稿闭环。作者确认后，原稿和审稿意见才会进入权威项目状态。

PRODUCT POSITION

An orchestration layer for writing, not another generate button.

AI Novel Writer does not sell model access and is not an online fiction platform. It stores project state, assembles context, manages chapter blueprints and draft versions, and connects generation, review, revision, and approval.

For each chapter, the workspace selects the relevant blueprint, characters, world facts, history summaries, and optional style references. The author remains responsible for the story and every accepted revision.

Version 0.8.6 strengthens manuscript import, reliable continuation, explicit model routing, and the human review loop.

TRACEABLE FLOW

从故事前提，一直走到下一章的上下文。

  1. 建立创作前提保存作品方向、关键矛盾和作者已经确认的原稿。
  2. 组织角色与世界观把人物、关系、规则和知识资料放回项目内部。
  3. 拆成大纲与章节蓝图让每一章有明确目标，而不是仅依赖一段临时提示词。
  4. 生成或导入章节草稿围绕当前章节资料调用本地或云端模型。
  5. 审稿、修稿、人工确认审稿意见可编辑和取舍，修订稿由作者决定是否合并。
  6. 形成定稿并继续定稿进入后续章节的连续性上下文。

TRACEABLE FLOW

From premise to the context that carries the next chapter.

  1. Define the premiseKeep direction, conflict, and approved manuscript material together.
  2. Build characters and world factsStore relationships, rules, and source material inside the project.
  3. Create outline and chapter blueprintsGive every chapter a deliberate target beyond a temporary prompt.
  4. Generate or import a draftCall a local or cloud model with chapter-specific context.
  5. Review, revise, approveEdit and select review notes before accepting a revision.
  6. Finalize and continueApproved copy becomes continuity context for future chapters.

CORE CAPABILITIES

作品、资料与生成过程，都留在同一个项目里。

01结构化创作流程

按阶段组织前提、角色、世界观、蓝图、草稿与定稿。

02章节级上下文

只取当前章节真正相关的资料，减少跨章跑题。

03审稿与修稿闭环

先形成可编辑审稿意见，再生成待合并修订稿。

04角色卡与项目资料

资料与小说项目绑定，避免旧窗口写入错误项目。

05参考文本与检索

导入常见文本格式；没有 embedding 时仍可全文检索。

06批量章节任务

单次 1–10 章，支持暂停与取消，失败会停止后续处理。

CORE CAPABILITIES

Story assets and generation history stay inside one project.

01Structured writing flow

Organize premise, characters, world facts, blueprints, drafts, and finals by stage.

02Chapter-level context

Use only material relevant to the current chapter.

03Review and revision

Edit review notes before generating a revision for approval.

04Project-scoped knowledge

Keep character cards and knowledge attached to the correct project.

05Reference search

Import common text formats and retain full-text search without embeddings.

06Batch chapter tasks

Run 1–10 chapters with pause, cancel, and fail-closed post-processing.

CURRENT BOUNDARIES

它帮助你管理创作，但不会替代作者的判断。

  • 不承诺任意第三方 API 只换 URL 和 Key 就能接入。
  • 不替代作者的创意、事实核查、版权判断与最终审校。
  • 不提供在线发布、阅读社区或云端模型账号。
  • DeepSeek Harness 插件仍是早期 MVP，能力不足桌面版的 10%，不能替代完整桌面工作流。

CURRENT BOUNDARIES

It manages the process; it does not replace the author.

  • Not every third-party API works by changing only a URL and key.
  • Creative decisions, fact checking, copyright judgment, and final review remain with the author.
  • It does not provide publishing, a reader community, or hosted model accounts.
  • The DeepSeek Harness plugin is an early MVP with less than 10% of the desktop app's capability.
