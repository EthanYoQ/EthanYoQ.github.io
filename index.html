Ethan / EthanYoQ 是谁？这个 AI LAB 的定位是什么？

Ethan 是一位独立 AI 工具开发者。AI LAB 是一个面向真实生产力痛点的个人实验田，致力于把日常高频、繁琐的重复劳动转化为稳定、可检验的桌面工具。

核心作品包括 AI 长篇小说写作工作台、小红书图文内容工作台、发票一键整理与 Windows 语音输入法。所有作品坚持开源透明，无论是源代码还是工具，都免费向所有人开放。

这里的 AI 工具与市面上的商业云端工具有什么核心区别？

1. 开源透明与完全免费：我坚持的不是本地优先，而是开源透明、免费做出来的工具，无论是源代码还是工具，都免费向所有人开放。

2. 零会员与自带模型（BYOK）：不设商业订阅套路与按月扣费。用户既可以使用云端模型 API（如 DeepSeek、OpenAI、Gemini），也可以接入本地离线模型（如 Ollama），不收取任何软件平台会员费。

项目可以直接下载体验吗？支持哪些操作系统？

所有项目均开源并提供 GitHub Release 安装包。AI Novel Writer 支持 Windows 与 macOS，Whisper Input 目前专注 Windows，发票整理与小红书工作台支持跨平台运行。每个作品详情页均附带源码、真实演示视频与最新安装包入口。
